# The Application — Flipper Zero
Reconstructed source of the original GPIO bumper counter.

## Build on GitHub
Go to **Actions** > **Build The Application** > **Run workflow**. Once successful, open the run and download the **The-Application-FAP** artifact.

The workflow targets official Flipper firmware commit `9981d9d4` (Dev, 2026-10-30).

## Important limitations
This is a reconstruction, not the recovered original source. The original custom 32x32 XBM image bytes are missing; the graphic is blank. The precise original screen layout is unverified. The build has not been tested yet.
